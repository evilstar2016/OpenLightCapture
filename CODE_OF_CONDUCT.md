# 社区行为准则 / Code of conduct

本准则适用于本仓库的 Issue、PR、评审及与项目相关的交流。

## 交流方式

- 尊重不同经验、语言和背景。围绕问题、代码和证据讨论，给出可操作的反馈。
- 使用真实、可复现的信息；明确区分已验证结果、推测和未完成的工作。
- 尊重他人的隐私、署名和劳动，提交截图与日志前先脱敏。
- 不接受骚扰、歧视、威胁、人身攻击、垃圾信息，以及未经允许公开他人私人资料。

有问题可向维护者 `evilstar2016` 请求沟通。没有合适的私密渠道时，可先通过 Issue 请求联系方式，不要公开私人证据。涉及安全漏洞时使用 [安全政策](SECURITY.md) 的渠道。

维护者可根据具体行为要求修改内容、隐藏或删除不当内容，并限制继续参与。处理时考虑事实、严重程度和重复情况，不把技术分歧本身视为违规。

## English

This code applies to issues, pull requests, reviews, and project-related discussions.

Be respectful across experience levels, languages, and backgrounds. Discuss behavior, code, and evidence; give actionable feedback. Distinguish verified results from assumptions, and respect privacy, attribution, and others' work.

Harassment, discrimination, threats, personal attacks, spam, and disclosure of private information without permission are not acceptable.

Ask the maintainer, `evilstar2016`, for an appropriate contact channel when needed. If none is available, request one in an issue without exposing private evidence. Use [SECURITY.md](SECURITY.md) for vulnerabilities.

Maintainers may request edits, hide or remove inappropriate content, and restrict participation based on severity and repetition. Technical disagreement alone is not misconduct.
