# 获取帮助 / Support

## 先检查

- 阅读 [使用指南](docs/USER_GUIDE.md)，核对权限是否在退出并重新打开应用后生效。
- 快捷键可能与飞书等应用冲突；先从菜单栏开始截图，以区分快捷键和采集问题。
- 长图先用静态正文、小步滚动验证，并避开固定栏和动态区域。
- 使用截图时记录应用版本/构建号、macOS 版本、芯片架构、模式、显示器缩放和复现步骤。

在 [GitHub Issues](https://github.com/evilstar2016/OpenLightCapture/issues) 选择问题、建议或翻译模板。中文、英文均可。提问可使用空白 Issue，并写清已经尝试的操作。

可附日志片段或合成页面的截图；先去掉账号、路径、私密聊天及其他人的信息。不要上传应用的整个 `Assets/`、`Working/` 或完整私人剪贴板内容。安全问题请走 [SECURITY.md](SECURITY.md)。

本仓库未公布单独的客服邮箱或付费支持渠道，也不承诺固定回复时限；Issue 也不代表对某项功能或修复时间的承诺。

## English

Read the [user guide](docs/USER_GUIDE.md) first. After granting permissions, quit and reopen the app. If the shortcut fails, try the menu bar. For scrolling problems, start with static content, small scroll steps, and an area without fixed bars.

Use [GitHub Issues](https://github.com/evilstar2016/OpenLightCapture/issues) for bugs, feature requests, translations, or usage questions. Include the app version/build or commit, macOS version, chip architecture, capture mode, display scaling, steps, and expected/actual behavior. Chinese and English are welcome.

Share only redacted diagnostics or synthetic captures. Do not upload private asset/work directories, credentials, or clipboard contents. Report vulnerabilities through [the security policy](SECURITY.md). This repository lists no separate support mailbox or paid support channel and promises no fixed response time.
